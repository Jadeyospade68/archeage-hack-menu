## 🧩 About

**ArcheAge Hack Menu** is a curated list of ArcheAge open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource tracker, map notes
- **Quality-of-Life Helpers** — inventory catalog, build planner, overlay notes
- **Research Notes** — trade route layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Route Notes — plan trade runs from any checkpoint
- Resource Tracker — visualize node and loot markers
- Replay Notes — record and review session runs
- Playback Speed — adjust menu playback for study (0.1x to 5x)

### Wallhack
- Item Catalog — browse gear, colors, mounts, cosmetics
- Custom Build Notes — organize skill and gear setups
- Map Visibility — improved map and radar clarity

### Aimbot
- Study Mode Notes — segment study on any layout
- Camera Control — manually adjust camera mid-session
- Craft Buffer Notes — chain complex crafting steps in the planner
